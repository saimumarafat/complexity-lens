# Changelog

## 0.2.0
- Added **best, average and worst case** analysis with a reason for each, shown in the panel, CodeLens, status-bar tooltip and Markdown export.
- Case curves can be overlaid on the growth chart.
- Removed the line-by-line code listing from the panel (hot lines are still highlighted in the editor).
- Added "Copy as Markdown", an extension icon, and a comparison table with Best / Average / Worst / Space.
- Quicksort detection now recognises common pivot-index names.

## 0.1.0
- First release: time and space complexity, growth chart, operations bars, explanations, CodeLens, inline annotations, status bar.
